# Smart Diff Analysis

## Гибридный подход: diff-only vs repomix

При обновлении README.md расширение выбирает одну из двух стратегий
в зависимости от размера diff'а кода:

### Diff-only mode (по умолчанию)
Если `rawDiff.length <= README_AI_DIFF_MAX_SIZE`, используется только git diff
(текущий README + diff — без repomix). Быстро и эффективно для небольших изменений.

### Repomix mode
Если `rawDiff.length > README_AI_DIFF_MAX_SIZE`, выполняется repomix для полного
контекста проекта. Медленнее, но точнее для масштабных изменений.

## Переменные окружения

| Variable | Default | Description |
|---|---|---|
| `README_AI_DIFF_MAX_SIZE` | `5000` | Максимальная длина сырого diff'а (в символах) для diff-only режима. Больше — repomix. |
| `README_AI_DIFF_TRUNCATE` | `8000` | Обрезать diff до скольки символов перед отправкой AI. |

## Схема работы

```
                    ┌─────────────────┐
                    │  Читаем README  │
                    │  парсим hash    │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │  git diff <hash> │
                    └────────┬────────┘
                             │
                             ▼
              ┌──────────────┴──────────────┐
              │ diff.rawDiff.length          │
              │ <= DIFF_MAX_SIZE?            │
              └──────┬───────────────┬───────┘
                     │               │
                     ▼               ▼
            ┌────────────────┐  ┌────────────────┐
            │ Diff-only      │  │ Repomix mode   │
            │                │  │                │
            │ README + diff  │  │ repomix        │
            │ → AI           │  │ (README filter)│
            └────────┬───────┘  │ → AI           │
                     │          └────────┬───────┘
                     └───────┬───────────┘
                             ▼
                    ┌─────────────────┐
                    │ Пишем README.md │
                    │ + новый hash    │
                    └─────────────────┘
```

## Зачем гибрид?

- **Мелкие изменения (≤5000 символов):** repomix избыточен — тратит время, токены и может запутать AI лишним кодом. Diff'а достаточно.
- **Крупные изменения (>5000 символов):** diff фрагментирован, AI нужен полный контекст для точного README.

Порог намеренно консервативный. Можно настроить через переменные окружения.
