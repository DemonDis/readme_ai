# Генерация API документации

Создай полную API документацию для проекта на русском языке.

## Требования к документации

### Структура документа

1. **Обзор API** - краткое описание назначения API
2. **Аутентификация** - как получить токен, примеры
3. **Базовый URL** - основной endpoint
4. **Эндпоинты** - все доступные endpoints с:
   - Метод (GET, POST, PUT, DELETE)
   - Путь
   - Описание
   - Параметры (query, path, body)
   - Ответы (коды и формат)
   - Примеры запросов/ответов
5. **Модели данных** - описание используемых структур
6. **Коды ошибок** - стандартные ошибки и их описание
7. **Лимиты** - ограничения API (если есть)

### Формат

- Используй таблицы для параметров и ответов
- Приводи примеры в формате curl
- Указывай типы данных
- Добавляй схему взаимодействия через Mermaid

### Стиль

- Официальный технический стиль
- Максимальная полнота информации
- Понятное объяснение для разработчиков
